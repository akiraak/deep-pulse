[NVIDIA NemoClaw](https://docs.nvidia.com/nemoclaw/latest/) is an open source stack that simplifies running OpenClaw always-on assistants more safely, with a single command. It installs the NVIDIA OpenShell runtime, part of the NVIDIA Agent Toolkit, a secure environment for running autonomous agents, and open source models like NVIDIA Nemotron.

NemoClaw incorporates policy-based privacy and security guardrails, giving you control over your agents' behavior and data handling. This enables self-evolving claws to run more safely in clouds, on prem, RTX PCs, DGX Spark, and DGX Station.

You can use open models like NVIDIA Nemotron locally on your dedicated system. A privacy router also connects agents to cloud-based frontier models, allowing agents to develop new skills within defined privacy and security guardrails. By combining powerful open source models with built-in safety measures, NemoClaw simplifies and secures AI agent deployment.

Get Started:

``` lang-auto
curl -fsSL https://nvidia.com/nemoclaw.sh | bash
```

Or tell your agent: Help me install [NVIDIA NemoClaw: Deploy Safer AI Agents in a Single Command](http://nvidia.com/nemoclaw){.inline-onebox}

NemoClaw has a Discussion tab on GitHub: [NVIDIA/NemoClaw · Discussions · GitHub](https://github.com/NVIDIA/NemoClaw/discussions){.inline-onebox}

This is the **best** place to go to ask questions, find solutions, and get help from the NemoClaw team!

There's also a NemoClaw Discord channel to hang out, share what you are working on, and build cool things together. Join the conversation: [NVIDIA Developer](https://discord.gg/XFpfPv9Uvx){.inline-onebox}
