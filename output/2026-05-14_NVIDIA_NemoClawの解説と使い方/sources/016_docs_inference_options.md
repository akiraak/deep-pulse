# Inference Options[\#](#inference-options "Link to this heading"){.headerlink}

NemoClaw supports multiple inference providers. During onboarding, the [`nemoclaw`{.docutils .literal .notranslate}]{.pre}` `{.docutils .literal .notranslate}[`onboard`{.docutils .literal .notranslate}]{.pre} wizard presents a numbered list of providers to choose from. Your selection determines where the agent's inference traffic is routed.

## How Inference Routing Works[\#](#how-inference-routing-works "Link to this heading"){.headerlink}

The agent inside the sandbox talks to [`inference.local`{.docutils .literal .notranslate}]{.pre}. It never connects to a provider directly. OpenShell intercepts inference traffic on the host and forwards it to the provider you selected.

Provider credentials stay on the host. The sandbox does not receive your API key. Local Ollama and local vLLM do not require your host [`OPENAI_API_KEY`{.docutils .literal .notranslate}]{.pre}. NemoClaw uses provider-specific local tokens for those routes, and rebuilds of legacy local-inference sandboxes migrate away from stale OpenAI credential requirements.

## Choosing the Right Option for Nemotron[\#](#choosing-the-right-option-for-nemotron "Link to this heading"){.headerlink}

NVIDIA Nemotron models expose OpenAI-compatible APIs across every supported deployment surface, so two onboarding options can route to Nemotron.

  Where Nemotron is hosted                                                      Onboard wizard option                            Why
  ----------------------------------------------------------------------------- ------------------------------------------------ ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
  [`build.nvidia.com`{.docutils .literal .notranslate}]{.pre} (NVIDIA-hosted)   **Option 1: NVIDIA Endpoints**                   NemoClaw sets the base URL to [`https://integrate.api.nvidia.com/v1`{.docutils .literal .notranslate}]{.pre} for you and validates the model against the build catalog.
  Self-hosted NIM container                                                     **Option 3: Other OpenAI-compatible endpoint**   NIM exposes an OpenAI-compatible [`/v1/chat/completions`{.docutils .literal .notranslate}]{.pre} route. Point the base URL at your NIM service and enter the Nemotron model ID.
  Enterprise NVIDIA AI Enterprise gateway                                       **Option 3: Other OpenAI-compatible endpoint**   Enterprise gateways front Nemotron with the same OpenAI-compatible contract. Use the gateway's base URL and your enterprise token.
  vLLM, SGLang, or TRT-LLM serving Nemotron weights                             **Option 3: Other OpenAI-compatible endpoint**   Each runtime exposes Nemotron through [`/v1/chat/completions`{.docutils .literal .notranslate}]{.pre}. Use the runtime's base URL and the model ID it reports.
  Local NIM started by the wizard                                               **Local NVIDIA NIM** (experimental)              Requires [`NEMOCLAW_EXPERIMENTAL=1`{.docutils .literal .notranslate}]{.pre} and a NIM-capable GPU. NemoClaw pulls and manages the container for you.

For Option 3, the API key environment variable is [`COMPATIBLE_API_KEY`{.docutils .literal .notranslate}]{.pre}. Set it to whatever credential your endpoint expects, or any non-empty placeholder if your endpoint does not require auth.

## Model Router[\#](#model-router "Link to this heading"){.headerlink}

The Model Router option uses the [`routed`{.docutils .literal .notranslate}]{.pre} inference profile in [`nemoclaw-blueprint/blueprint.yaml`{.docutils .literal .notranslate}]{.pre}. When you select it, NemoClaw starts the router proxy on the host, waits for its health endpoint, registers the [`nvidia-router`{.docutils .literal .notranslate}]{.pre} provider with OpenShell, and creates the sandbox with the same [`inference.local`{.docutils .literal .notranslate}]{.pre} route the agent uses for other providers. The sandbox does not call the router port directly.

The router model pool lives in [`nemoclaw-blueprint/router/pool-config.yaml`{.docutils .literal .notranslate}]{.pre}. The default pool routes between NVIDIA-hosted Nemotron models and uses the [`tolerance`{.docutils .literal .notranslate}]{.pre} value to choose the lowest-cost model whose predicted quality stays within the configured threshold. To use the router in scripted setup, set:

    $ NEMOCLAW_PROVIDER=routed NVIDIA_API_KEY=<your-key> nemoclaw onboard --non-interactive

## Experimental Options[\#](#experimental-options "Link to this heading"){.headerlink}

The following local inference options are experimental. Local NIM and managed vLLM install/start require [`NEMOCLAW_EXPERIMENTAL=1`{.docutils .literal .notranslate}]{.pre}; an already-running vLLM server appears directly in the onboarding selection list.

  Option             Condition                                                                                                                                       Notes
  ------------------ ----------------------------------------------------------------------------------------------------------------------------------------------- -------------------------------------------------------------------------------------------------------------------------------------------------------------
  Local NVIDIA NIM   NIM-capable GPU detected                                                                                                                        Pulls and manages a NIM container.
  Local vLLM         vLLM running on [`localhost:8000`{.docutils .literal .notranslate}]{.pre}, or a supported DGX Spark, DGX Station, or Linux NVIDIA GPU profile   Auto-detects the loaded model when vLLM is already running. Can install or start a managed vLLM container for supported profiles after experimental opt-in.

For setup instructions, refer to [[Use a Local Inference Server]{.std .std-doc}](use-local-inference.html){.reference .internal}.

## Validation[\#](#validation "Link to this heading"){.headerlink}

NemoClaw validates the selected provider and model before creating the sandbox. If credential validation fails, the wizard asks whether to re-enter the API key, choose a different provider, retry, or exit. Transient upstream validation failures are retried before the wizard reports a provider failure. The [`nvapi-`{.docutils .literal .notranslate}]{.pre} prefix check applies only to [`NVIDIA_API_KEY`{.docutils .literal .notranslate}]{.pre}. Other provider credentials, such as [`OPENAI_API_KEY`{.docutils .literal .notranslate}]{.pre}, [`ANTHROPIC_API_KEY`{.docutils .literal .notranslate}]{.pre}, [`GEMINI_API_KEY`{.docutils .literal .notranslate}]{.pre}, and compatible endpoint keys, use provider-aware validation during retry.

  Provider type                           Validation method
  --------------------------------------- ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
  OpenAI                                  Tries [`/responses`{.docutils .literal .notranslate}]{.pre} first, then [`/chat/completions`{.docutils .literal .notranslate}]{.pre}.
  NVIDIA Endpoints                        Tries [`/responses`{.docutils .literal .notranslate}]{.pre} first with a tool-calling probe that matches OpenClaw behavior. Falls back to [`/chat/completions`{.docutils .literal .notranslate}]{.pre} if the endpoint does not return a compatible tool call.
  Google Gemini                           Tries [`/responses`{.docutils .literal .notranslate}]{.pre} first with a tool-calling probe that matches OpenClaw behavior. Falls back to [`/chat/completions`{.docutils .literal .notranslate}]{.pre} if the endpoint does not return a compatible tool call.
  Other OpenAI-compatible endpoint        Tries [`/responses`{.docutils .literal .notranslate}]{.pre} first with a tool-calling probe that matches OpenClaw behavior. Falls back to [`/chat/completions`{.docutils .literal .notranslate}]{.pre} if the endpoint does not return a compatible tool call.
  Anthropic-compatible                    Tries [`/v1/messages`{.docutils .literal .notranslate}]{.pre}.
  NVIDIA Endpoints (manual model entry)   Validates the model name against the catalog API.
  Compatible endpoints                    Sends a real inference request because many proxies do not expose a [`/models`{.docutils .literal .notranslate}]{.pre} endpoint. For OpenAI-compatible endpoints, the probe includes tool calling before NemoClaw favors [`/responses`{.docutils .literal .notranslate}]{.pre}.
  Local NVIDIA NIM                        Uses the same validation behavior as NVIDIA Endpoints and skips the [`/v1/responses`{.docutils .literal .notranslate}]{.pre} probe for endpoints that do not expose it.
