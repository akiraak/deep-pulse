# 保存形式

章は連番付きの `.md` ファイルとして保存します。

## ファイル名の規則

`NN_章タイトル.md` の形式で、`NN` の連番がページ順を決めます。

## グラフの例

章ページ内でも Chart.js が使えます。

```chart
{
  "type": "bar",
  "data": {
    "labels": ["扉", "第1章", "第2章", "第3章"],
    "datasets": [{ "label": "ページ数", "data": [1, 1, 1, 1], "backgroundColor": "#8b0000" }]
  },
  "options": { "plugins": { "title": { "display": true, "text": "ページ構成" } } }
}
```
