# 図のクリック拡大表示（ライトボックス）＋ 図サイズ問題の再発防止

## ユーザー指示

> 図をクリックしたら拡大表示されるようにしてください。また今回の問題が再発しないようにCLAUDE.mdに記載してください

「今回の問題」= 扉ページの系譜図が `flowchart LR`（横一列）だったため、コンテナ幅（最大800px）に収めるよう全体が縮小され、ノード内の文字が小さく潰れて読みづらかった件。

## 目的

1. 記事内の Mermaid 図をクリックすると、画面いっぱいに拡大表示（ライトボックス）して細部まで読めるようにする。
2. 「横長レイアウトで図が縮小され文字が潰れる」問題を、記事生成時に避けられるよう CLAUDE.md にルールとして明記する。

## 対応範囲

- **対象 = Mermaid 図（SVG）**。SVG はベクターなので拡大しても文字がくっきり保たれる。
- **対象外 = Chart.js グラフ（canvas）**。canvas はラスターで、単純拡大すると粗くなる（クローンしても描画内容が複製されない）。今回はスコープ外とする。
- 全記事共通の変更。レンダラー `src/render.ts` の1か所を直せば、扉ページ・全章・既存記事すべてに反映される（再ビルドで反映）。

## 実装方針（`src/render.ts`）

レンダラーの3要素にそれぞれ追記する。既存の Mermaid 出力 HTML（`<div class="mermaid-wrapper">...<svg>`）はそのまま使う。

### 1. CSS（`CSS` 定数に追記）

- `.mermaid-wrapper svg { cursor: zoom-in; }` — 図がクリック可能だと分かるカーソル。
- ライトボックス用スタイル:
  - `.dp-lightbox` — 全画面オーバーレイ（`position:fixed; inset:0; z-index:1000; background:rgba(28,28,28,0.85)`）。既定は非表示、`.open` で `display:flex`（中央寄せ）。
  - `.dp-lightbox-inner` — 拡大した図を載せる枠（明るい背景・角丸・スクロール可）。
  - `.dp-lightbox-close` — 右上の「×」閉じるボタン。
  - サイトのカラースキーム（生成り色＋臙脂）に合わせる。

### 2. ライトボックス用 HTML（`</body>` 直前に1回だけ出力）

```html
<div id="dp-lightbox" class="dp-lightbox" role="dialog" aria-modal="true">
  <span class="dp-lightbox-close" aria-label="閉じる">×</span>
  <div class="dp-lightbox-inner"></div>
</div>
```

### 3. JS（`</body>` 直前に1回だけ出力、依存なしの素のJS）

- **イベント委譲**で実装する（`document` に click リスナーを1つ）。Mermaid は非同期で SVG を描画するため、描画完了を待たずに済む委譲方式が安全。
- 挙動:
  - `.mermaid-wrapper svg` がクリックされたら、その SVG を `cloneNode(true)` してライトボックスに載せ、`viewBox` から算出した倍率で**ビューポートいっぱい（幅94% / 高さ92%）にフィット**させて表示。小さい図は拡大、大きい図は収まるよう縮小される。
  - オーバーレイ／×ボタンのクリック、または `Esc` キーで閉じる。
- ベクター拡大なので、縦型・横型どちらの図でも鮮明に読める。

## CLAUDE.md の更新（再発防止）

「### 図・相関図（Mermaid.js）の活用」の **注意事項** に以下を追記する:

- **直列（線形）の流れは縦型 `flowchart TB` にする** — 時系列・系譜・処理フローのように一本道でノードが続くものを `flowchart LR` で横一列に並べると、コンテナ幅（最大800px）に合わせて図全体が縮小され、ノード内の日本語が小さく潰れる。縦に伸ばせば幅で縮小されず文字サイズを保てる。
- 既存の「`flowchart LR` を使う」ガイドは、**中心から多数のリーフ（7個以上）が放射する俯瞰図**向けの指針であることを明確化する（この場合は TB だとリーフが横に潰れるため LR が良い）。つまり「放射状の俯瞰図 = LR / 直列の流れ = TB」と使い分ける。
- 補足として、図はクリックで拡大表示できる旨を一言添える。ただし**既定サイズでも読めるよう設計する**ことを前提にする（拡大は補助）。

## 確認方法

1. `npm run build:site` で再ビルド。
2. Playwright（導入済み）でビルド後の扉ページをヘッドレス起動し、図クリック→ライトボックスが開き拡大SVGが表示されること、Esc/オーバーレイで閉じることをスクリーンショットで確認。
3. 既存の他記事（チャート併用記事）でレイアウト崩れ・JSエラーがないことを確認。

## 影響範囲・リスク

- 変更は `src/render.ts` 1ファイルと `CLAUDE.md`。記事の Markdown は変更しない。
- 追加する CSS クラス名は `dp-` 接頭辞で既存と衝突しない。
- JS は依存なし・イベント委譲のみで、Mermaid/Chart.js の既存初期化に干渉しない。
